# AI Personalized Email Campaign Sender

## Summary

This repository contains an exported n8n workflow (My-workflow.json) that automates a personalized email campaign. The workflow reads customer data from Google Sheets, uses OpenAI to generate personalized marketing email content, performs recipient validation, and sends the messages through Gmail. The project is intended to be imported into an n8n instance where the required service credentials are configured.

## How It Works

Input → Processing → Validation → Output

- Input
  - The workflow source is a Google Sheets spreadsheet containing customer rows (name, email, and any other fields used to personalize messages).

- Processing
  - For each customer row, the workflow calls OpenAI to generate personalized email subject and body copy using the provided customer data.

- Validation
  - Before sending, the workflow validates recipient addresses (the exported workflow includes a validation step; check the imported nodes for exact validation logic).

- Output
  - Validated, personalized messages are sent using a Gmail node configured in n8n. The workflow may also write status or results back to Google Sheets or log them in n8n executions depending on the exported node configuration.

Important: The actual nodes, triggers, and node-level configuration are defined inside My-workflow.json. The workflow's trigger node (cron, webhook, manual trigger, etc.) determines how and when the automation runs; review the imported trigger node and adjust it to your needs.

## Key Features

- Reads customer data from Google Sheets.
- Uses OpenAI to generate personalized marketing email subject and body per row.
- Validates recipient email addresses before sending.
- Sends emails via Gmail using configured n8n credentials.
- Exported as a single n8n workflow JSON file (My-workflow.json) ready to import.

## Tech Stack

- n8n (workflow engine)
- Google Sheets (data source)
- OpenAI (LLM used to generate personalized email content)
- Gmail (email sending)

## Setup Instructions

1. Install and run n8n according to your preferred environment (local, Docker, or hosted). This repository does not include n8n itself.

2. Import the workflow:
   - In your n8n instance, import My-workflow.json (Workflow → Import). This will recreate the nodes and connections exported from the original workflow.

3. Configure credentials in n8n for:
   - Google Sheets (access to the spreadsheet containing customer data)
   - OpenAI (API access to generate personalized content)
   - Gmail (account authorized to send emails)

   Do not store credentials in this repository. Configure them securely inside your n8n instance or its credential store.

4. Review the imported workflow:
   - Check the trigger node to set how the workflow should run (scheduled, webhook, or manual).
   - Verify which Google Sheet and range are referenced and update them if needed.
   - Inspect the OpenAI node prompts and parameters and adjust tone or instructions as required.
   - Confirm the validation node's logic and the Gmail node's send settings.

5. Run a test on a small dataset or in a staging account before sending to production recipients.

## Usage

- After importing and configuring credentials, the workflow runs according to its trigger node.
- Expected result: for each processed row in Google Sheets, a personalized email is generated by OpenAI, validated, and then sent through Gmail. Execution logs and node output appear in n8n's executions view.
- If the workflow writes back results (status, timestamps, error messages) to Google Sheets, check the configured sheet/range for per-row outcomes.

## Security Notes

- Do not commit secrets, API keys, or credential files to this repository.
- The exported workflow (My-workflow.json) can contain references to sheet IDs or other identifiers—review and remove any sensitive identifiers before publishing if necessary.
- Manage OpenAI and Gmail credentials through n8n's credential management and never checked into version control.

## Limitations

- This repository is an exported n8n workflow JSON and is not a standalone application. It requires an n8n runtime to execute.
- The repository does not include installers, runtime images, or explicit environment variable names; those are provided/managed by your chosen n8n deployment.
- Sending limits and usage quotas are governed by the configured Gmail account and OpenAI account and are not controlled by this workflow.
